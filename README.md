# 🛒 E-Commerce SQL Analysis

## 📌 Project Overview

This project analyzes an e-commerce dataset using SQL to uncover
customer behavior, order trends, product performance, and revenue insights.

The project was created as a practical Data Analytics project to
demonstrate SQL skills using MySQL.

---

## 🎯 Objectives

The main objectives of this project are:

- Analyze customer distribution
- Analyze order status and payment methods
- Calculate total and completed revenue
- Calculate Average Order Value (AOV)
- Identify high-value customers
- Identify best-selling products
- Analyze category-wise revenue
- Analyze monthly revenue trends
- Identify repeat customers
- Use advanced SQL techniques for business analysis

---

## 🛠️ Tools & Technologies

- MySQL
- MySQL Workbench
- SQL

---

## 🗄️ Database Structure

The database contains five main tables:

```text
Customers
    │
    └── Orders
            │
            └── Order Items
                    │
                    └── Products
                            └── Categories
```
